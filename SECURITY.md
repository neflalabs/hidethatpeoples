# Security & Privacy Policy

## 🔒 Privacy First Guarantee
- **100% On-Device**: HideThatPeoples does not collect, track, or transmit any analytics, crash logs, or telemetry.
- **Zero Third-Party Trackers**: No advertising SDKs, no Google Analytics, no Firebase Analytics.
- **Local Debugging Only**: The built-in ADB engine communicates solely with the local loopback interface (`127.0.0.1`) on your own device over standard TLS. It never accepts incoming connections from external networks.
- **Root Safety**: When root privilege (`su`) is used, commands are restricted exclusively to standard Android shortcut management (`cmd shortcut clear-shortcuts`).

## 🛡️ Reporting a Vulnerability
If you discover a security concern or vulnerability in this repository, please reach out privately via GitHub issue with security label or direct contact to neflalabs.
